# CVForge
### Professional CVs for Everyone - Free, Open Source, AI-Powered

CVForge writes professional CVs from simple user input. No subscriptions. No internet required. No paywalls. Ever.

## Who Is This For?
- Job seekers who cannot afford professional CV writers
- People in developing countries
- Fresh graduates
- Anyone who wants a better CV for free
